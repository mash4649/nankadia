### 内容基準の暫定抽出（未確定）

今回の修正から見える傾向を、正式仕様ではなく暫定基準として記録する。

1. 数: 標準は3個前後。5個以上は体験上の必然性がある場合だけ採用を検討する。
2. 時間: 屋内の短時間体験は3〜10分、屋外歩行は15〜30分を目安とする。35分以上・75分は別途妥当性確認が必要。
3. 自己完結: 選択肢・必要語句・手順はカード内に提示し、利用者の事前作成や予備知識に依存しない。
4. 主動作: 1カード1つの主動作に絞り、成果物または気づきは1〜3個程度にする。
5. 一人で成立: 他者や採点のためだけの記憶課題を避け、一人でも観察・意味づけが残る設計にする。
6. 安全と入手性: 特別な購入・外部検索・動的情報を必須にせず、屋外・身体活動には安全範囲を明記する。
