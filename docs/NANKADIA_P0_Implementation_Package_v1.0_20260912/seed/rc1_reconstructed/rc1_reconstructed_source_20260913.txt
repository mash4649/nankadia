復元できます。**RC1のCORE候補36件は以下です。**  
`★` はRC1監査で本文変更が明示されたため、元本文＋Rewrite指示から復元した箇所です。★以外はSeed Candidate本文を基本的にそのまま維持しています。

なお、RC1はまだ `RELEASED` ではなく、**100% Human Review前のRelease Candidate**です。36件すべてがG0/G1をPASSし、G3・Discovery・Coverage上の致命問題なしと判定されています。

### 評価値の読み方

`G3 = Action Clarity / Feasibility / Outcome Potential / Context Legibility` の4項目です。Discoveryは0〜4で、「自分では思いつかなかった体験・見方を返せるか」の強さを見る指標です。RC1ではG3最低値2未満は置かない設計です。

# 36件を残した全体根拠

RC1の判断は「面白そうな36案を選んだ」というより、**Portfolioとして初期Calibrationを壊しにくい36件にした**と見るのが正確です。

36件に絞った後も、10 Archetypeすべてが `CORE >= 3` かつ `Semantic Cluster >= 3` を満たし、Bootstrap Coverageは100%。

さらに、

- 最大MechanicでもObservation **16.7%**
- Photo/Videoは **11.1%**
- 予約・営業時間・在庫・リアルタイム価格・特定店舗必須は **0**
- 公共交通のDynamic Access依存もCoreから除外

となっています。

つまりRC1の36件は、

**「種類を増やす」より、低摩擦・安全・その場で実行可能・外部依存が少ない・体験の偏りが小さい状態でProduct Proofを始める**

ことを優先した構成です。

- **36件のID・RC1タイトル・採否・G3・Discovery：確定**
